# Folder: Static Assets
Folder ini digunakan untuk menyimpan semua aset statis yang mendukung keindahan dan fungsi interaktif dari halaman web.
- **Isi**:
    - Folder `css/` (untuk file gaya/stylesheet seperti Tailwind, Bootstrap, atau CSS kustom).
    - Folder `js/` (untuk logic JavaScript kustom di sisi client).
    - Folder `images/` (untuk logo CampRent, ikon, banner, atau gambar default perlengkapan gunung).
- **Tujuan**: Menyediakan aset yang bisa diakses langsung oleh browser tanpa perlu diproses oleh logika backend.
